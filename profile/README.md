Sporaflow is a vendor-agnostic agentic orchestrator, built first for developers.

You talk to one manager in a single chat. The manager creates members for separate tasks and follows their work through their reports. Each member runs in a real terminal, on an AI command-line tool you already have.

- Give the manager your ideas as they come, without waiting for an agent to finish.
- Every member works in its own terminal. You can open any of them and talk to a member directly.
- A team can combine AI command-line tools from different providers.
- Role cards, project notes and the conversation history help you pick the thread of a project back up.

You install and sign in to your own AI command-line tools. Sporaflow provides none and manages no AI account or credentials.
