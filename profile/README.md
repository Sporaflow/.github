## How it works

1. You talk to the manager in a single chat, and give it your ideas as they come.
2. The manager creates members for separate tasks and follows their work through their reports.
3. Each member runs in its own terminal, on an AI command-line tool you already have.

## Why Sporaflow

| You | Sporaflow |
| :-- | :-- |
| Have another idea while an agent is still working | Takes it now. The manager does not wait for an agent to finish. |
| Want to see what a member is doing | Lets you open its terminal and talk to it directly. |
| Use command-line tools from different providers | Lets a team combine them. |
| Come back to a project later | Keeps role cards, project notes and the conversation history to pick the thread back up. |

<br>

> Sporaflow provides no AI tool and manages no AI account or credentials. You install and sign in to your own.
